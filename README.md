# Proyectos

## Contable — Sistema de gestión empresarial

Aplicación web para ayudar a los negocios a gestionar información como ventas, inventario y finanzas desde un mismo lugar. Incluye una pantalla de inicio de sesión y un panel de administración para consultar y gestionar empresas y su actividad.

- Desarrollé la interfaz con React.js, Redux, Axios y CSS puro.
- Construí el backend con Node.js y Express, y utilicé Sequelize para la comunicación con PostgreSQL.
- El proyecto se desarrolló de forma intermitente durante aproximadamente dos años, entre pausas y periodos de trabajo.
- Puedes visitar el proyecto en [Contable](https://vocal-lebkuchen-af95ce.netlify.app/login).

## D&J Clean Service — Sitio web para empresa de limpieza

Sitio web estático creado para una empresa de limpieza con sede en Estados Unidos. Presenta sus servicios y permite a los visitantes conocer la empresa y solicitar un presupuesto.

- Desarrollé el sitio con Next.js, priorizando la presentación clara de la empresa y sus servicios.
- Incluye secciones de servicios, información de la empresa, reseñas y contacto, además de llamadas a la acción para solicitar presupuestos.
- El sitio ofrece opciones de visualización en inglés y español.
- El proyecto se preparó para un cliente, pero la venta no llegó a concretarse por circunstancias ajenas al desarrollo.
- Puedes visitar el sitio en [D&J Clean Service](https://tiny-kringle-0b01f1.netlify.app/).
